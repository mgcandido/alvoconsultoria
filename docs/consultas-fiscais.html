Consultas Fiscais

Consulte na hora os principais códigos fiscais brasileiros. As tabelas de CFOP, CST, CSOSN e alíquotas de ICMS funcionam offline (instantâneas); o CNAE é consultado ao vivo na base do IBGE.

Fontes e observações

CFOP, CST, CSOSN e alíquotas internas de ICMS são tabelas oficiais (Ajuste SINIEF / Convênios CONFAZ / RFB), com dados derivados do projeto de código aberto mcp-fiscal-brasil (licença MIT). O CNAE é consultado ao vivo na API do IBGE. A alíquota de ICMS informada é a interna padrão da UF — produtos específicos podem ter alíquotas diferenciadas.

Consulta NCM

Pesquise a Nomenclatura Comum do Mercosul em tempo real. Informe o código ou descrição e clique em Buscar para consultar os dados oficiais com a classificação tributária CBS/IBS.

Exemplos:

Pronta para consultar

Digite um código NCM completo (ex: 2202.99.00) ou parte da descrição (ex: refrigerante) e clique em Buscar.

Os dados são consultados em tempo real na API oficial — BrasilAPI (fonte: SISCOMEX/MDIC).
